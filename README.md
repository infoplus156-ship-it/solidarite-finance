# Solidarité Finance — projet APK Codemagic

Application Flutter Android avec :
- Français
- English
- Bosanski
- Dons
- Prêts solidaires
- Projets à financer
- Demande de financement
- Tableau de bord
- Paiement en mode démonstration

## Compilation avec Codemagic
1. Créer un dépôt GitHub/GitLab et y envoyer ce projet.
2. Dans Codemagic, connecter le dépôt.
3. Utiliser le workflow `android-release`.
4. Lancer le build.
5. Récupérer `app-release.apk` dans les artefacts.

Important : les paiements réels, comptes utilisateurs, base de données, KYC et gestion réglementaire doivent être ajoutés avant une mise en production.
